\# 🏥 MedLLMOps — Medical RAG Production System



Production-grade Medical LLMOps pipeline with RAG, guardrails, and evaluation.



\## 🎯 Goal



Medical question answering using PubMed literature with:

\- Real citations

\- PII redaction

\- Medical advice detection

\- Hallucination checks

\- RAGAS evaluation



\## 🚧 Status



\- \[x] Phase 0: Setup

\- \[ ] Phase 1: Data collection (PubMed API)

\- \[ ] Phase 2: RAG pipeline

\- \[ ] Phase 3: Guardrails

\- \[ ] Phase 4: RAGAS evaluation

\- \[ ] Phase 5: FastAPI serving

\- \[ ] Phase 6: Deployment



\## 🛠️ Tech Stack



\- \*\*LLM\*\*: Groq (Llama 3.3 70B)

\- \*\*Embeddings\*\*: sentence-transformers (local, free)

\- \*\*Vector DB\*\*: ChromaDB

\- \*\*RAG Eval\*\*: RAGAS

\- \*\*Guardrails\*\*: Presidio (PII)

\- \*\*API\*\*: FastAPI + Docker
